# DekaLab — Comparador de carreras

## Ejecutar en local

Requiere Node.js 22.13 o posterior.

```bash
npm install
npm run dev
```

Abre <http://localhost:3000>.

## Compilar y ejecutar la versión de producción

```bash
npm run build
npm start
```

Las carreras se guardan en el almacenamiento local del navegador.
